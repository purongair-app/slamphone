# SLAM Card Reader — เครื่องอ่านบัตรประชาชน USB

รองรับเครื่องอ่าน USB ที่ Windows แสดงผ่าน PC/SC เช่น SCR3310/TDK3310V2 โดยใช้ pyscard ไม่ต้องมี SDK แบบเสียเงิน โปรแกรมนี้ยังไม่ได้ทดสอบกับเครื่องจริงของร้าน

## ติดตั้งบน Windows 10/11

1. ติดตั้ง Python 3.13 แบบ 64-bit จาก https://www.python.org/downloads/windows/ (เลือก Python ที่ยังรองรับบนเครื่อง และติดตั้ง Python launcher)
2. ติดตั้งไดรเวอร์เครื่องอ่าน USB จากผู้ผลิต https://rd-comp.com/downloads/product-drivers/smartcard-reader/
3. แตกชุด ZIP ไว้ในโฟลเดอร์ของคุณ แล้วดับเบิลคลิก `install-windows.cmd` ครั้งเดียว หากหา Python ไม่พบให้ติดตั้ง Python พร้อม launcher ก่อน
4. ทุกครั้งที่เริ่มทำงาน ดับเบิลคลิก `start-windows.cmd` แล้วเปิดหน้าต่างนี้ค้างไว้ โปรแกรมรับคำขอเฉพาะในคอมเครื่องนี้ที่ 127.0.0.1:8765 ไม่เปิดให้เครื่องในเครือข่าย
5. เข้าระบบร้านบน Chrome หรือ Edge ในคอมเครื่องเดียวกับที่เสียบ USB เปิด **ข้อมูลลูกค้า → เพิ่มลูกค้า** หรือ **รับงานใหม่ → เปิดใบงานซ่อมใหม่** แล้วกด **อ่านบัตรประชาชน / เสียบบัตร**
6. หน้าต่างอ่านบัตรจะเปิดขึ้น ขออนุญาตลูกค้า แล้วกด **เริ่มอ่านเมื่อเสียบบัตร** จากนั้นเสียบบัตรภายใน 25 วินาที ระบบอ่านชื่อ เลขบัตร วันเกิด และที่อยู่
7. ตรวจชื่อบนหน้าต่างอ่าน กด **ใช้ข้อมูลนี้เติมแบบฟอร์ม** ข้อมูลจะเติมให้อัตโนมัติ กรอกเบอร์โทรเพิ่มเติม แล้วกดบันทึกพร้อม OTP ตามกติกาของระบบร้าน

เลขบัตรที่มีลูกค้าเดิมแล้วจะเลือกข้อมูลลูกค้าเดิมมาแก้ไข ไม่สร้างรายการซ้ำ การอ่านไม่ได้บันทึกทันที ข้อมูลบัตรจะบันทึกในฐานข้อมูลร้านเมื่อผู้ใช้กดบันทึกและยืนยัน OTP เท่านั้น โปรแกรมเชื่อมต่อไม่เขียนข้อมูลบัตรลงดิสก์และไม่ทำบันทึก HTTP

## เมื่อมีปัญหา

- หน้าต่างเปิดไม่ได้: อนุญาตป๊อปอัปสำหรับระบบร้าน
- เปิด 127.0.0.1 ไม่ได้: เปิด start-windows.cmd บนคอมเครื่องเดียวกับเว็บก่อน ตรวจว่ามีข้อความ SLAM Card Reader ready
- ไม่พบเครื่องอ่าน: ตรวจ Device Manager และไดรเวอร์ PC/SC จากผู้ผลิต เสียบ USB ใหม่ และปิดโปรแกรมอ่านบัตรอื่นที่อาจจับเครื่องอยู่
- อ่านไม่สำเร็จ: เสียบชิปให้ถูกด้าน บางบัตร/ไดรเวอร์อาจต้องปรับคำสั่ง APDU ต้องทดสอบกับเครื่องจริงของร้าน
- ใช้มือถือเปิดเว็บแต่ USB เสียบอยู่คอมอีกเครื่อง: อ่านไม่ได้ ชุดนี้อ่านจากเครื่อง Windows ที่ต่อ USB โดยตรงเท่านั้น
- ไม่ทราบวันเดือนเกิดครบ: ระบบเว้นว่าง ไม่สร้างวันที่สมมติ

## รายละเอียดความปลอดภัย

บริการผูกกับ loopback เท่านั้น ปฏิเสธ Host/Origin อื่น ปฏิเสธ GET เพื่ออ่าน ใช้ token หน้าอ่านครั้งเดียวอายุ 5 นาที ไม่มี CORS และห้ามฝังหน้าอ่านใน iframe ผู้ใช้ต้องสั่งอ่านและยืนยันส่งข้อมูลในหน้าต่างท้องถิ่นแต่ละครั้ง หน้าเว็บตรวจ origin/source/nonce ของ postMessage ข้อมูลจะไม่ถูกใช้เมื่อฟอร์มถูกปิด

## การทดสอบ

`python -m unittest discover -s card-reader -p 'test_*.py'` จากโฟลเดอร์ repository ตรวจ parser, APDU status/chaining, checksum, วันที่ไทย, และขอบเขต HTTP ด้วยข้อมูลสมมติ ไม่แทนการทดสอบฮาร์ดแวร์จริง
