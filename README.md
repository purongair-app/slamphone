- ระบบสำรองไฟล์ก่อนรีเซ็ตข้อมูลธุรกิจ และระงับบัญชีพนักงาน
- ส่งอีเมลผ่าน MailApp ตามโควตาบัญชี Google; อีเมลสมัครและอนุมัติที่ส่งไม่สำเร็จอยู่ในคิวให้เจ้าของร้านลองส่งใหม่

## การยืนยันการเปลี่ยนแปลง

การบันทึกข้อมูลร้านโดยเจ้าของหรือพนักงาน, การจัดการคำขอพนักงาน, การตั้งรหัสผ่านเจ้าของ, การรีเซ็ต และการเปลี่ยนอีเมลเจ้าของ ต้องใช้ OTP 6 หลักจากอีเมลผู้ทำรายการ อายุ 10 นาที ใช้ได้ครั้งเดียวและผูกกับข้อมูลและเซสชันนั้น การเปลี่ยนอีเมลใช้ OTP ทั้งกล่องเดิมและกล่องใหม่ ระบบยกเลิกเซสชันและรหัสผ่านเดิม เจ้าของใหม่เข้าทางอีเมลแล้วตั้งรหัสผ่านใหม่ได้ การสมัครและรีเซ็ตรหัสผ่านพนักงานใช้ลิงก์ยืนยันทางอีเมลอยู่แล้ว

`configureOwnership` ย้ายสิทธิ์แอปโดยใช้บัญชีเก็บข้อมูลเดิม ไม่สร้างฐานข้อมูลใหม่ ไม่ย้าย Google Drive/Spreadsheet และไม่ให้บัญชีเก็บข้อมูลเข้าระบบในฐานะเจ้าของอีกต่อไป

## ไฟล์

`app.js` และ `styles.css` เป็นหน้าร้านที่ build แล้ว ส่วน `apps-script/Code.gs` เป็น backend สำหรับติดตั้งใน Apps Script

## เครื่องอ่านบัตร USB Type-C (มือถือ/แท็บเล็ต)

ระบบรับงานซ่อมและข้อมูลลูกค้ามีช่อง **นำเข้าข้อมูลจากแอปเครื่องอ่านบัตร** รองรับไฟล์ UTF-8 แบบ JSON, CSV หรือ TXT (คู่ `ชื่อช่อง: ค่า`) และการวางข้อความบน Android, iOS/iPadOS, Windows, macOS โดยตรวจเลขบัตร 13 หลัก วันเกิด และให้ผู้ใช้ยืนยันก่อนกรอกฟอร์ม ระบบไม่ส่งไฟล์บัตรขึ้นเซิร์ฟเวอร์โดยอัตโนมัติ การบันทึกจริงยังใช้ขั้นตอนยืนยันสิทธิ์เดิม

**หมายเหตุสำคัญ:** เว็บไซต์ไม่อ่านเครื่อง USB-C/CCID โดยตรง เพราะ WebUSB ป้องกัน smart-card interfaces ต้องใช้แอปอ่านบัตรของผู้ผลิตที่รองรับเครื่องจริง (และสามารถส่งออก JSON/CSV/TXT) หรือพัฒนาแอปเชื่อมต่อเฉพาะรุ่นเพิ่ม Android อาจอ่าน USB Host ผ่านแอปเนทีฟได้เมื่อรุ่นรองรับ; iPhone/iPad ต้องได้รับการรองรับโดยแอปและอุปกรณ์อย่างชัดเจน ไม่ใช่ทุกเครื่อง USB-C อ่านบัตรประชาชนไทยได้ โปรดตรวจสอบยี่ห้อ/รุ่น/Vendor ID/Product ID ก่อนพัฒนาการอ่านชิปโดยตรง

ชุด Windows PC/SC เดิมใน `card-reader/` เลิกเชื่อมจากหน้าเว็บแล้ว เก็บไว้เป็นไฟล์อ้างอิงเท่านั้น
