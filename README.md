## การยืนยันการเปลี่ยนแปลง

การบันทึกข้อมูลร้านทั่วไปใน `/api/store` (รับงานซ่อม, ขายสินค้า, สต๊อก, ลูกค้า, การเงิน, ตั้งค่าร้านและจัดการหน้าร้าน) **ไม่ต้องใช้ OTP อีกต่อไป** แต่ผู้ใช้ต้องเข้าสู่ระบบและผ่านการตรวจสิทธิ์กับ revision ป้องกันข้อมูลเขียนทับ การสมัครพนักงานยังยืนยันอีเมลและต้องได้รับอนุมัติจากเจ้าของร้าน การจัดการบัญชีผู้ใช้/คำขอพนักงาน, ตั้งรหัสผ่านเจ้าของ, รีเซ็ตทั้งร้าน และเปลี่ยนอีเมลเจ้าของ ยังคง OTP 6 หลัก อายุ 10 นาที ใช้ครั้งเดียว ผูกกับข้อมูลและเซสชัน การเปลี่ยนอีเมลเจ้าของยังใช้ OTP จากอีเมลทั้งเก่าและใหม่ ทั้งนี้รีเซ็ตข้อมูลทั้งร้านเป็นการทำลายข้อมูล จึงยังบังคับยืนยันรหัสผ่านและทำไฟล์สำรองก่อนรีเซ็ตด้วย

`configureOwnership` ย้ายสิทธิ์แอปโดยใช้บัญชีเก็บข้อมูลเดิม ไม่สร้างฐานข้อมูลใหม่ ไม่ย้าย Google Drive/Spreadsheet และไม่ให้บัญชีเก็บข้อมูลเข้าระบบในฐานะเจ้าของอีกต่อไป

## ไฟล์

`app.js` และ `styles.css` เป็นหน้าร้านที่ build แล้ว ส่วน `apps-script/Code.gs` เป็น backend สำหรับติดตั้งใน Apps Script

แหล่งข้อมูลต้นฉบับหน้าร้านอยู่ใน `src/` สร้างใหม่ด้วย `npm install` และ `npm run build` ตรวจตรรกะ backend ด้วย `npm run verify` (mock services; ต้องตรวจการใช้งานจริงเพิ่มเติม)

โครงการ Apps Script: https://script.google.com/home/projects/1n4PlBFoY1kFiSiVnpAFAgttmp483dXRtfG6C-GECDRGeo_E-rKt-rYn2/edit

เมื่อเปลี่ยน backend ต้องสร้าง deployment version ใหม่ เมื่อเปลี่ยน frontend ให้อัปเดตไฟล์ build บน GitHub Pages

## แบบฟอร์มลูกค้าและงานซ่อม

คืนหน้าจอให้เป็นแบบก่อนเพิ่มเครื่องอ่านบัตร โดยยกเลิกการอ่านบัตรจาก USB/Type-C การนำเข้าข้อมูลบัตร และช่องกรอกเลขบัตรประชาชนกับวันเกิดในแบบฟอร์มลูกค้าและงานซ่อม ข้อมูลเดิมที่เคยบันทึกไว้จะไม่ถูกลบออกจากฐานข้อมูล การแก้ไขลูกค้า/ใบงานเดิมยังรักษาฟิลด์เก่าที่ซ่อนไว้ ไม่ใช้เครื่องอ่าน และไม่กรอกเลขบัตรหรือวันเกิดให้รายการใหม่ ชุดเดิมใน `card-reader/` ไม่มีการเรียกใช้งานจากหน้าเว็บแล้ว

## การเปิดใช้งานการยกเลิก OTP สำหรับการบันทึก

1. `app.js` บน GitHub Pages และ `src/lib/change-confirmation.ts` เปลี่ยนให้การบันทึกทั่วไปไม่ขอ OTP แล้ว หน้าเว็บยังมี compatibility fallback ถ้า Apps Script รุ่นเดิมตอบ HTTP 428
2. **ต้องคัดลอก `apps-script/Code.gs` เวอร์ชันล่าสุดเข้า Apps Script โครงการเดิมและ deploy เป็นเวอร์ชันใหม่** ที่ https://script.google.com/home/projects/1n4PlBFoY1kFiSiVnpAFAgttmp483dXRtfG6C-GECDRGeo_E-rKt-rYn2/edit โดยลงชื่อเข้าบัญชีเก็บข้อมูลเดิม ไม่สร้างโปรเจ็กต์หรือฐานข้อมูลใหม่
3. ถ้าใช้หน้าจัดการเว็บไซต์หน้าร้านใน Apps Script ให้คัดลอก `apps-script/StorefrontAdmin.html` รุ่นล่าสุดลงไฟล์ HTML ชื่อ `StorefrontAdmin` ในโปรเจ็กต์ Apps Script เดิมด้วย แล้วเข้า **Deploy → Manage deployments → Edit → Version: New version → Deploy** เพื่อคง URL `/exec` เดิม
4. รีเฟรชแอปบนมือถือ/คอมพิวเตอร์หลังการ deploy แล้วทดสอบบันทึกงานซ่อม/ลูกค้า (ไม่มี OTP) และแก้ไขบัญชีพนักงาน (ยังมี OTP)

*หมายเหตุ: การ push GitHub ไม่ได้อัปเดต Google Apps Script deployment ที่เผยแพร่อยู่โดยอัตโนมัติ*
